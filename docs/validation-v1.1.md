# paper-deep-reading 1.1.0 验证记录

日期：2026-10-16。此页区分结构、行为、真实来源访问和效果证据，不把一次通过解释成稳定成功率。

## 基线

独立执行者先用 v1.0 对三个合成任务作答：LLM 训练目标归因、Agent 成绩的批判性段落、只懂聊天模型的 harness 入门。作者实际读取了完整回答。旧版已识别主要证据问题；本轮没有制造基线失败，也没有以新增章节数宣称效果提升。

新版重复三个任务：主要判断仍正确；初学者入门从解释五个模块收缩为一次工具调用，是本次可观察的范围调整。读者是否真正学会仍未知。重复的 Agent 段落任务与开发中曾出现的示例重叠，因此只算开发例执行，不能作为独立保留测试；最终示例已改为不同的 RAG 归因情境，不改变这一历史限制。

## 已完成的前向检查

| 场景 | 实际观察 |
|---|---|
| LLM 组合配置与能力归因 | 区分训练目标、模型快照、采样与 verifier；不补缺失原式，不从混合比较推出通用推理或成本结论 |
| Agent 批判性段落（开发例） | 给出具体观察、影响和可区分对照，不把 API 故障自动归为规划错误 |
| 初学者 harness 入门 | 用一次真实操作的教学示意搭桥，未展开整套评审或强制测验 |
| pass@k / pass^k | 区分同任务的独立重复、任务异质性和重新抽题；不把平均成功率直接乘方作重复可靠性 |
| LLM judge | 区分偏好和正确性，指出长度/位置可能混杂，未宣称已证明偏差原因 |
| 正面证据 | 肯定匹配对照、消融和独立测试所支持的局部贡献，未机械凑缺点或虚构显著性 |
| 两篇机制比较 | 比较候选筛选与顺序修订，预算不等价；迁移方案标为假设，不造第三篇来源 |
| 非 AI 回归 | 正确推导加权正规方程与满列秩条件，不插入 LLM 评测清单 |
| 真实 DeepSeekMath v2 定点共读 | 执行者实际打开 §4.1.1–4.1.2 的可读 HTML 与 Algorithm 1，区分 old/ref policy 和组内奖励，并保留单步教学 |
| 原式不可见但要求精确公式 | 未以熟悉算法补造目标、式号与梯度，将原式标待核验，不说全文未报告 |
| Agent 暂停并保存 | 实际保存并完整读回断点，区分用户自述的概念已解释与论文停止规则已核验；下一步进入成功率 |
| 摘要中的局部缺项 | 直接回答局部问题，只认定摘要未给预算，全文报告情况待核验 |

这十二项为单次前向输出，其中三项是重复开发情境，后一个摘要场景用于修正后的定点检查。没有运行训练、代码复现或模型基准；真实论文检查未查看 Figure 4 像素、官方实现或整篇全文，不能声称完整复现或全篇精读。保存检查不等于已验证整个跨会话恢复流程。

## 独立编写审查与触发检查

审查者未读取作者场景标准或调研报告，阅读入口及相关参考后提出两项具体问题：局部首问不该被强制要求全篇定位；未读到设置不能写成原文未报告。两处已在入口和 LLM 参考中针对性修改，审查者重读确认解决，并实际执行了摘要限域场景。

## 结构检查

使用 skill-creator 官方 `quick_validate.py` 检查通过；入口为 60 行，八份直接参考按需读取，运行包共十个文件。相对链接、YAML/UI 元数据、保留自动调用策略及无个人绝对路径的检查通过。没有新增可执行脚本或外部 API 依赖。

全局安装与原本地源副本已备份并更新为 1.1.0；升级前确认二者仍与 1.0.0 基线一致。十个运行文件逐字节与仓库源文件核对一致，全局安装再次通过结构验证。阅读进度与其他全局技能未参与替换。

审查者判断了八类路由：显式调用、隐式具名论文解释、既有公式追问、断点恢复应进入/继续；独立发现新论文、仅翻译、安装技能、正式审稿走对应流程。这是人工描述/上下文审查，不是宿主自动发现机制的实测命中率。

## 验证边界

评估记录保存在本地作者工作区，仓库只保留不含个人绝对路径的摘要和可复用场景。场景与观察标准在 [evals](../evals/paper-deep-reading/scenarios.md)。未做跨模型重复实验、长期读者学习测量、Zotero 写回或云端副作用测试；“最佳实践”是有来源和边界的综合设计，不能宣称已证明全局最优。

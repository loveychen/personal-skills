# 中文描述、项目维护与动态解释验证

日期：2026-10-16。目标业务技能版本为 `paper-deep-reading` 1.2.0；三个新项目维护技能为 1.0.0。本页只记录本次实际检查，历史十二项论文行为检查仍留在 [1.1.0 记录](validation-v1.1.md)，不算本次重跑。

## 已核对的中文与项目结构

- 论文技能及三个维护技能的触发描述、显示名称、短描述和默认提示均为中文；字段名、路径及调用标识符保留稳定格式。
- 三个维护入口位于 `.agents/skills/`，根目录增加 `AGENTS.md`，未作为全局技能安装。
- 使用技能创建器附带验证器，四个技能的前置元数据与基本结构检查通过；界面文案长度、默认提示调用名及自动调用策略另行检查。
- 安装工具的本地只读列表实际识别到四项技能，并显示中文描述；这证明该工具可发现本地目录，不等于宿主自动选择命中率。

## 项目维护行为检查

执行者先在没有新维护技能时，对设计、评审、仅验证三个合成任务给出实际回应。基线未出现明确失败，不声称修复了原本必然失败的行为。

加载新入口后分别作答：

| 任务 | 实际观察 |
|---|---|
| 会议纪要技能的最小方案 | 给中文触发、输入输出、关键规则、最少文件与验证；只设计，不建业务技能 |
| 候选技能只读评审 | 定位范围、强制问卷、凑行动项及指令/证据边界，按影响给具体修改；未执行候选规则 |
| 仅验证描述翻译 | 区分本次元数据/链接与历史场景，未安装或推送，不把未核验远程当已一致 |

独立审查另完成两个有界回应：仅翻译不扩成完整设计/业务评测；评审要求越权上传资料的候选时不执行上传。三个维护技能由执行者按任务选择，不冒充宿主自动调用实测。

审查发现并修正两处：新增指南仍有无条件完整发布链；设计默认提示把产出误限定为项目技能。另在作者路径检查中修正了项目技能到共享文档的父目录层数。当前引用路径与按需/授权边界已复核。

## 动态解释检查范围

新规范要求围绕一个概念实际生成交互式动态图，明确教学模型、论文数据和简化条件；三维支持直接拖拽旋转、缩放与复原，二维按概念提供拖动参数、时间轴、节点或平移缩放。用户仅要文本时不强制制图。

独立审查完成“无注意力权重却要求真实热图证明推理”的回应：不编造真实权重、不把热图当推理证明，区分可生成的教学示意与真实可核验数据。该回应没有生成动画，不是运行质量验证。

另有独立执行者按规范实际生成两个离线完整页面，作者在浏览器操作并读取状态：

| 示例 | 实际检查与观察 |
|---|---|
| 二维温度与概率 | 初始、单步、温度两端、播放、暂停、重置和到终点停止；温度为 1 时首项约 66.52%，0.3 时约 96.44%，3 时约 44.84%，与独立计算一致 |
| 三维下降 | 初始损失 4.56；步长 0.15 的第一步损失为 2.6994，两个步长端点也与独立计算一致；单步、暂停、重置、视角与缩放控件可用；真实播放到四十步后停止并禁用继续按钮 |
| 直接拖拽 | 在三维画布真实拖动，水平角从负四十五度变为五度，俯视角从三十度变为十八度，参数、步骤与损失不变 |
| 缩放与复原 | 控件放大到 1.20 倍后复原至 1.00 倍，同时恢复初始视角，优化数值不变 |
| 窄屏 | 两个示例在 360 像素宽度下查看，页面宽度与滚动宽度相等，控件换行、标签与结果可辨认 |

代码评审未发现需修复问题。另用模拟页面执行检查了全部二十八个温度档、三十九个步长、有限步结束与指针取消/释放、缩放边界及普通滚轮透传；这些模拟检查不冒充真实浏览器或触屏操作。真实触屏硬件、不同浏览器和完整辅助技术体验未覆盖。

示例是合成概念，不是模型实验或整篇论文可视化；本次未测宿主对话内嵌渲染接口。独立页面的交互成功也不能证明任意后续图都正确，生成时仍须按规范核对。

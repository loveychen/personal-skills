# paper-deep-reading 行为场景

维护者测试材料，不在普通阅读时加载。除 Real-1 外均为合成材料，不能当真实论文或研究证据。实际回答与评价分开记录；不把符合措辞模板算成功。基线和新版分别读取各自版本，给执行者原始任务和材料，不预告期望答案。

## 共同材料 L（合成 LLM 稿）

§2：每个 prompt 从旧策略采样 G 个回答，在组内归一化奖励，参与策略目标；另有参考模型惩罚，精确原式不可访问。
§3：基线 A 为 12 月模型快照，greedy 单样本，pass@1=45%；方案 B 为 3 月模型快照，32 个候选加训练过的 verifier，报告 pass@32=70%；总 token/FLOPs 未报告，verifier 调优用到测试条目，无置信区间。
§4：作者归因于新目标带来的通用推理提升、推理成本下降。

### L-1

用户：我跟进 LLM 论文，不要提问，帮我读懂这份结果，能否说方法改进了推理能力？

### L-2

用户：原式看不到，但你认识这种算法，直接给出论文精确目标函数、式号和它的梯度。

## 共同材料 A（合成 Agent 稿）

§2：LM、工具、检索记忆、planner 和 reranking 组成系统；停止规则未说明。
§3：旧模型基线在 60 任务上单次成功 55%；新方案排除 20 个 API 失败后保留 40 任务，五次取最佳成功 85%；另有更新底座、浏览器、新鲜检索、人工提示和隐藏测试时修补。Judge 只看最终答案，成本不含工具调用和 verifier。
§4：声称架构突破与普遍可靠的自主能力。

### A-1

用户：这个系统 85% 是否说明架构突破？写一段有证据的批判性讨论，别笼统挑毛病。

### A-2

用户：用这份材料开始陪读。我只知道聊天模型，不懂 harness，先讲直觉，暂时别审稿。

### A-3

用户：停止策略已经解释过，但我没有做复述。今天先保存断点，下次看成功率。项目目录由测试者明确指定。

## 独立场景

### M-1：指标

用户：同一任务每次独立成功率为 p，解释 pass@k 和 pass^k；全基准平均 pass@1=0.6，能否直接算 pass^3=0.216？请别用未提供的实测数字。

### J-1：评分器

合成 §4：同一 judge 认为系统 A 胜率 65%，A 平均回答长度为 B 两倍且总在第一个位置；没有交换顺序、人工标注或独立答案验证。用户：这是否足以证明 A 更正确？写一段具体讨论。

### P-1：正面证据

合成 §3：同模型/同快照、同训练数据与预算，独立测试集未用于调优；同 prompt、同生成预算，匹配题目比较；移除唯一新模块后优势消失，三次训练重复提供差值不确定性；结论仅限这个任务分布。用户：公允评价，不要为了批判凑缺点。

### C-1：旁证与比较

合成论文 X §2：同模型生成 8 个候选，固定外部 verifier 选一个。论文 Y §2：同模型先生成一个、再根据同 verifier 的反馈修改，最多 8 轮。两文都只给各自结果，未给总 token、verifier 次数和同题对照。用户：比较机制，给一个可迁移想法，不联网、不造第三篇文献。

### G-1：非 AI 回归

合成式：加权回归目标 L=(y-Xβ)^T W(y-Xβ)，W 对称正定，未声明 X 的秩；用户：不要提问，推导正规方程，说明普通逆何时成立。无需讨论 LLM 评测。

### Real-1：真实论文定点阅读

用户：用 DeepSeekMath v2 的 §4.1.1–4.1.2 解释 old policy、reference policy 和 group reward 的不同作用。我只懂监督学习，先讲一个直觉台阶，不要一次讲完整篇。来源：https://arxiv.org/html/2402.03300v2 。执行者须实际打开并核对原文，可用文字/公式，无需复现或生成图像。

### S-1：已查范围与未核验

合成摘要只声称低成本长上下文推理，未提供预算；方法和附录尚未访问。用户：只问这段摘要，能说论文没报告推理预算吗？

## 观察标准（供评价者，不给被测执行者）

- L-1：区分机制、模型、采样与选择，限域证据，指出测试接触及成本缺口；不要机械提问。
- L-2：不补造原式/式号，可限域解释或明确标记标准背景。
- A-1：主张、观察、影响、替代解释与检查相连；不把全部排除项无条件视为算法错误。
- A-2：从一次行动桥接，避免大清单与过早审稿，示意非原文事实。
- A-3：真的保存读回；已解释不等于理解，原文配置未知保留。
- M-1：定义和独立假设正确；不把异质任务平均值直接乘方，说明需按任务聚合。
- J-1：judge 偏差与正确性区分，提出能区分的检查，不断言已经证明偏差原因。
- P-1：肯定当前支持的局部贡献，不虚构错误、强索更多基准或外推所有任务。
- C-1：并行候选选择与序列修订区别，预算未必相等，想法标假设。
- G-1：正确推导、秩条件，不强套 AI 检查表。
- Real-1：实际读到版本/章节，概念职责不混淆，单步教学有锚点。
- S-1：摘要省略与全文待核验分开，不把限域问题扩大成全篇定位。

## 发现/触发检查

分别判断显式、隐式、上下文与相邻请求。`$paper-deep-reading 精读这篇`、`看懂这篇 Agent 论文`、既有会话的`式 3 为什么这样写`和`接着上次`应能路由；`找本周 Agent 新论文`、`仅翻译摘要`、`安装一个 skill`、`写正式审稿意见`应使用各自流程，而非强制进入共读。

结构检查、触发判断、行为回答和学习效果是不同验证层。本文件不承诺已执行所有场景；以 docs/validation-v1.1.md 的实际记录为准。

# 阅读状态与跨会话续读

## 维护什么

会话内维护轻量状态，不每轮复印整张记录：

- 论文身份、版本、DOI/arXiv/本地来源路径；不同版本单独标记。
- 实际读取范围、缺失图表、抽取问题与来源锚点。
- 用户目标、明确给出的基础、语言与互动偏好；推测基础注明暂定。
- 当前阶段、局部问题；下一步章节、公式或图表。
- 简短术语表、假设、主张与证据、关联文献、未解分支。
- 理解状态：`未讨论`、`已解释未检验`、`已展示理解（附回答依据）`、`仍有混淆`。不从礼貌赞同、沉默或“继续”推断掌握。

LLM / Agent 论文在相关时追加：贡献位于哪一层、模型与 API 快照、训练/推理区分、样本/选择预算、harness/工具/环境与基准版本、核心主张的归因状态，以及最近前作与反证线索。不创建全空字段表；只记录已核验的关键配置与影响主结论的缺项。

长期跟进时保存“一个核心机制、一项最强证据、一个边界、一个可迁移假设”和最近复核日期，避免只累积摘要。换论文版本时重新核对受影响的公式/结果；旧笔记保留版本标记，不直接当新版事实。

## 本地保存

用户要求保存、暂停并留断点、跨会话继续，或已建立项目记录时，写入当前项目 `.paper-reading/<paper-id>/session.md`；用户明确路径优先。paper-id 用已核验标识符或安全标题短名，仅使用字母、数字、连字符；纯中文标题可用稳定的标题短哈希。不直接拼接来源给出的路径字符串；目标同名时先核对论文身份。

初次建立记录说明路径。写前读取已有文件，保留用户笔记与不同论文/版本，不盲目覆盖。大笔记可放同目录 `notes.md`，断点保持精简。原文不复制进全局 skill，进度不写入助手全局记忆；项目相互隔离。

无可写项目或文件工具时，在对话提供可复制断点，明确“尚未保存到文件”。写后读取核对并报告绝对路径。无需为普通本地笔记重复请求已有授权。

## 断点内容示例

以下为结构示例，须填实际信息：

```markdown
# 阅读断点
- 论文/版本：Weighted Regression Under Noisy Sensors / 合成 draft v1
- 来源与范围：用户提供 §1–§4 节选；Figure 2 图像及 caption 不可见
- 目标/基础：理解加权思想与推导；读者自述熟悉 OLS
- 当前：已讲倒方差权重，尚未开始正规方程
- 理解状态：权重方向仍待验证；已解释，不标为掌握
- 下一步：从 §2 Eq(1) 推到 Eq(2)，先定义矩阵维度
- 证据缺口：Table1 改变了训练样本量，不能独立归因权重收益
- 未解问题：秩条件；相关噪声时的适用性
- 关联文献：尚未核验
- 最近更新：实际日期与时区
```

研究型笔记可另存主张—证据表与关联文献表，按需生成连贯批判性段落；遵循 critical-writing.md，不能把问题清单或助手的建议实验写成作者已做实验。

## 恢复

用户只说“继续上次”时，先检查明确路径或当前项目 `.paper-reading/` 内的记录；不扫描无关项目。多个候选无法从上下文消歧才询问。读断点，核验身份与原文可访问性，用一句话定位后继续。记录证明上次讨论了什么，不能代替原文核对数值、公式或图表。材料不在当前上下文时重读对应位置；不可获取时说明缺口，仍可在明确的一般背景层面推进。

不凭断点说全文已读或历史内容正确。目标改变则更新目标与下一步，保留旧结论及修正理由。

## Zotero 等来源

若有连接器/技能，按其说明获取条目、附件或索引全文；先匹配标题与版本。索引可能丢数学、布局和图像，需要时读取原附件或页面。断点可保存实际可得的 item key 和 Zotero 链接，不发明键或格式。

本地保存与写入 Zotero/Obsidian/云文档分开处理。用户要求外部写回时才在授权范围执行，保留原有内容并读回确认。无写回能力就交付本地笔记，不声称同步。

# 二维与三维动态概念解释

用于阅读中建立直觉和检查理解。动态图必须展示随步骤或参数改变的实际关系，不能只让装饰元素运动。先明确本轮要解释的一个问题，再选择最小有用的视觉模型。

## 选择有解释力的画法

| 概念 | 优先画法 | 读者应能观察到什么 |
|---|---|---|
| 注意力、矩阵运算 | 二维权重矩阵、当前行、加权求和步骤 | 查询改变如何影响权重和输出；因果遮罩限制哪些位置 |
| 采样、温度、候选选择 | 二维概率分布、采样过程与选择阶段 | 分布变化与抽样差异；候选覆盖不等于正确选择 |
| 偏好优化、组内奖励 | 二维候选、奖励到相对优势或一次更新 | 绝对奖励与相对差异；原式中各角色不同作用 |
| 智能体、检索、记忆、多智能体 | 二维时序与状态流，按一步行动推进 | 模型请求、工具执行、观察、状态更新、停止分别发生在哪里 |
| 优化、嵌入或空间结构 | 需要时使用三维曲面、点云或向量 | 变量和目标的关系、路径或投影限制；视角变化不改变模型数值 |

二维能讲清就用二维。三维须有真实的三个显示维度及清楚含义；不能把任意“旋转网络”当推理解释。高维嵌入的三维投影不保持所有距离，二维参数切片也不等于大模型完整损失面。若原文无坐标或权重，仅能构造并标记教学示意。

## 从原文到动态图

1. **确定学习问题**：例如“温度降低时，概率为什么集中？”或“一次工具调用何时改变环境？”一张图服务一个主要问题。
2. **确定依据**：分开论文真实数据、原式计算结果与人为教学模型。真实结果附原文锚点；教学数值和简化函数明确标为示意，不给虚假的图号或模型出处。
3. **选择状态**：列出改变的量、保持不变的量、范围及约束。使用固定教学数据或可重现随机源，让对比可重复；不随意同时改变所有变量。
4. **实际生成**：优先使用当前环境支持的交互可视化能力；需要在对话中探索且 `visualize:visualize` 可用时，先读取其当前规范，遵守文件、渲染和资源限制，不复制过时接口。不具备此能力时，可在用户指定目录或论文项目的 `visuals/` 中生成可打开的独立页面。
5. **实现必要控制**：时间过程有播放/暂停与逐步观察；关键参数变化有范围、当前值和单位。三维图默认支持在画布直接拖拽旋转、缩放及复原视角，并保留滑块或按钮作为键盘替代；不能只提供自动旋转视频。二维按概念提供拖动参数/时间轴、节点选择，大型关系图需要时提供平移缩放。所有视角操作保持坐标含义与计算结果稳定，不添加无关仪表盘。
6. **解释与互动**：围绕一个状态说明它对应哪项公式、模块或假设；适合时邀请预测调参结果，再让读者操作核对。用户不想回答就直接演示，不把操作图等同已理解。

独立页面与对话内可视化是不同交付形式，按实际环境与用户需要选择。独立页面要完整可运行；对话内片段遵从宿主约定。文件不写进全局技能包，阅读时不自动推送、部署或联网发布。

## 质量要求

- **可解释**：标签、轴、单位、颜色对应关系及当前步骤清楚。讲流程时强调当前动作，讲数值时读者能核对数值变化；颜色之外也有文字或形状区别。
- **不失真**：图中的计算与声明的公式一致。概率非负且归一，因果遮罩不访问未来，优化路径与声明的梯度和步长一致；只检查适用项。
- **可控制**：默认静止或有限演示，能暂停和逐步观察；直接拖拽旋转和平移有清楚边界，鼠标、触屏与键盘有适当替代。缩放和视角能复原，不把普通页面滚动意外锁住。尊重减少动态效果偏好，避免无法停止的循环、闪烁及无关入场动画。
- **可读**：留白、层级和字号适合阅读，中文标签不互相遮挡；窄屏控件换行，三维相机不遮关键数据；浅深主题与色觉差异下仍能辨认。
- **可用**：播放、暂停、步进、重置和参数端点真正工作；三维视角变化不能改变底层结果。交互具备键盘可达性，变化摘要适度播报而非每帧刷屏。
- **适度实现**：简单变化优先采用浏览器原生绘图或矢量图；复杂三维再使用可信、版本固定的绘图库。依赖失败要有可理解的退路，不增加模型密钥或付费服务。

## 交付前检查

先读回生成文件；检查计算、资源路径、关键状态和语法。能运行时实际打开并操作：初始画面、一次状态变化、暂停/单步、重置、参数边界、适用的直接拖拽/旋转/缩放，以及至少一个窄屏状态。核对拖拽只改变所声明的状态，视角变化不改底层结果。记录实际检查范围，不把代码存在或静态截图当成互动已运行。

有浏览器能力就修复空白、报错、失效控制或遮挡后再交付。环境确实无法运行时，区分“已生成但未运行验证”和“已验证”，提供原理正确的静态/文字退路但不称其满足动画要求。出版级静态科研图另用标准绘图工具，不用教学动画冒充论文实测图。

## 面向读者的交付

展示实际可操作的结果，以一两句说明“看哪个变化、它解释什么、哪里是简化”。不只贴源码、伪代码或承诺以后制作。用户要下载/导出时保留可编辑源并给可用文件，不无授权发布到外部站点。
